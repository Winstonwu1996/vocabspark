## 🚩 红旗句（创始人必审）

> 按影响排序。无事实硬伤；#1/#2/#3 为本课高敏感 Rule 0 + 合成桥接的透明性处理，#4/#5 为低优先级措辞。

1. **[#高敏感 Rule 0] 「确有间谍 vs. 恐惧伤无辜」两面同体的处理**（贯穿 §1/§3/§4-4/§4-7/§7/§9/§10-2）
   - **问题**：本课是平台最高敏感 topic 之一。核心风险是滑向任一极端——要么把红色恐慌写成「纯粹的集体幻觉/迫害无辜」（抹掉 Hiss/Rosenberg 确有渗透的史实），要么写成「美国当时面对真威胁所以反共正当」（洗白对大量无辜者的摧毁）。
   - **narrative 现状**：全程**两面同体**处理——§7 把「安全 vs. 自由」设为必考张力且**明确不要学生选边、只分析机制**；§9 historiography 并列「真有威胁派(Venona)」与「恐惧失控派」并给中立综合；§10-2 直接清坑「不是冤枉了所有人，而是为抓极少数真间谍伤害了大量无辜者」。Rule 0 段（§8 末）显式写「不能说更文明、也不能说一样糟」。
   - **建议**：现状**合规且稳健**，是本课最该被审的设计点。创始人若认可「让学生看机制、不替学生下『真威胁还是假想敌』结论」这一定调，即可放行。**这是本课的灵魂判断点。**

2. **[#合成桥接] 两个合成桥接人物 + 双重 receiving-end 叠合**（§3）
   - **问题**：actor（HUAC 调查员/麦卡锡式参议员）与 receiving-end（上黑名单者 / 被挡门外的黑人退伍军人）均为虚构桥接人物；且 DEFAULT 视角**刻意把「黑名单受害者」与「被 redlining 挡回的黑人退伍军人」两种处境叠在一个角色位置上**。
   - **narrative 现状**：§3 **已显式标注**——调查员「虚构桥接人物，但身份完全写实，不给名字，因为他代表的是一整套调查机器」；receiving-end「虚构桥接人物，身份写实……刻意把两种 receiving-end 叠在一个位置上，因为恐惧与排斥常常落在同一批人身上」。EN 同。
   - **建议**：现状**合规**（合成成分透明、未冒充史料、身份写实）。唯一需创始人确认的是：**「黑名单受害者 + 黑人退伍军人」叠成一个 DEFAULT 角色是否接受**——这是教学设计选择（让一个视角同时承载「恐惧侵蚀自由」与「繁荣排斥他者」两条线），不是史实问题。建议接受；若要拆，storyboard 可设两张 receiving-end lens card。

3. **[#1] Wheeling 数字 205 / 57 的争议**（§1/§5A）
   - **问题**：McCarthy 自己对名单人数前后不一（advance copy 205 → 次日致杜鲁门信 + Congressional Record 用 57），名单从未公开、未被证实存在。
   - **narrative 现状**：§1 用「205」开场（最广为流传、task brief 口径），§4-5/§5A **已显式标注**「数字第二天就改成 57，再没对上过」「名单从从没公开」。处理**完全合规**。
   - **建议**：保持现状。列此条仅为透明。提醒下游 storyboard 引用「205」时必须沿用「数字自相矛盾、名单未公开」的标注，**禁止**当作确证事实排版。

4. **[#23/#8 §8 中国对照] 「恐惧政治」并置的非排名处理**（§8）
   - **问题**：§8 把麦卡锡主义与同期早期 PRC 政治运动（镇反/三反/五反）并置。风险是被误读为「美国也搞迫害所以两边一样/各打五十大板」或反向「别处更糟所以美国没事」。
   - **narrative 现状**：§8 Rule 0 段**显式**写「具体形式、规模、后果差别巨大，绝不能简单等同」「不做道德排名，只把……两个案例放在一起，让学生看见机制本身」「不能用『美国也搞迫害』相对化任何一方，也不能用『别处更糟』免除美国责任」。同时第一层桥（排华→麦卡锡，同一机制）落地扎实，对华裔学生切身。
   - **建议**：现状**合规且符合 task brief 的 §8 要求**（排华史呼应 + 同期新中国恐惧政治对照）。创始人若认可「只看机制、不排名」的定调即放行。低改动建议：storyboard 若展开 §8，narrator 一句重申「这是机制对照，不是规模或道德的等同」。

5. **[#19 措辞] William Levitt 名言 + Welch 名言的引语性质**（§5C/§5D）
   - **问题**：Welch「Have you no sense of decency」有逐字录音/速记（primary，铁证）；William Levitt「We can solve a housing problem...」属**广为引用的记述性引语**（主流来源一致归于他，但非档案逐字录音）。
   - **narrative 现状**：两句均作 primary source 节点引用。Welch 句无问题。Levitt 句 narrative 用「流传记述」措辞（CN §5C「Levitt 本人的辩解（流传记述）」/ EN "as recorded"），**未**伪称档案逐字。
   - **建议**：现状可接受（已用「流传记述/as recorded」留余地）。若想更严，可加一字「据广泛记述」。低优先级。**无把记述性引语排成档案原话的违规。**
