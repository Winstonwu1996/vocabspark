## 🚩 红旗句（创始人必审）

> 按影响排序。无事实硬伤；均为史前史固有的「区间/措辞」或「合成感官细节」与「史学立场 vs 事实」的边界确认。

1. **[#13] 身高数字「约 1.78 米 → 1.68 米」的来源链**（§4-8 / 附录 D）
   - **问题**：这组「男性平均身高从 5'10" 降到 5'6"」的数字来自 Jared Diamond 1987 的科普文章（他转引 1980s 古病理学，主要是 Dickson Mounds 等北美 + 希腊/土耳其骨骼研究）。它是**特定遗址样本**的估计，不是全球普适常数；学界对「身高下降幅度」有不同样本不同结论。
   - **narrative 现状**：已限定为「**一项**对希腊/土耳其骨骼的**研究估计**」「**约**」「**男性平均**」——措辞已收口，未当作普适事实。
   - **建议**：现状**合规**。若要更严，可在 reading 模块标注「这是某些遗址样本的研究估计，不同地区幅度不同」——但不必改 narrative。**身高下降的方向（农民更矮）是古病理学广泛共识，有争议的只是具体厘米数。**

2. **[#12] Çatalhöyük「最早大村镇之一」的措辞**（§2 L2 / §4-5 / 附录 A）
   - **问题**：Çatalhöyük 常被科普称「最早的城市」，但学界更严谨的说法是「最大、最完整保存的新石器**定居点/大村镇**之一」——它缺少后来意义上的「城市」特征（无明显公共/行政建筑、无中央权力机构）。「city」一词在专业语境有争议。
   - **narrative 现状**：CN/EN 均用「**大村镇**（big town / large settlement）」「已知最早的『大村镇』**之一**」，**刻意避开了「最早城市」这个有争议的措辞**。§5D 还专门点出「最早的大村镇长得和我们想的城市完全不一样」。处理**精准**。
   - **建议**：保持现状。**列此条仅为透明**——narrative 的措辞恰恰避开了这个常见坑，无需改。

3. **[#24/#25] 三个合成桥接主角 + 农家少女的具体劳损/饮食细节**（§3）
   - **问题**：这一万年**没有留下任何个人姓名**，所以三个主角（老猎人 / 哥贝克力工匠 / 农家少女）全部是**合成桥接人物**。农家少女身上的「磨麦致膝腕劳损」「麦糊毁牙」「生育更密」等具体细节，是把**真实的考古/古病理学模式**落到一个**虚构个体**身上。
   - **narrative 现状**：§3 **已对每个主角逐个显式标注**「虚构桥接人物，身份完全写实」「不给名字，因为这一万年没有为任何具体的人留下名字——而这恰恰是问题的一部分」；附录 C 整张表头也声明「这一万年没有留下任何个人的名字……写实合成桥接人物」。承载在少女身上的细节本身（劳损/毁牙/密育）都是真实考古模式，未伪造档案或具体姓名。
   - **建议**：**接受现状**（合成桥接人物已透明标注，符合 composite 红线；细节是真实模式的人格化，非凭空编造）。这是本课**唯一需创始人确认「以合成个体承载真实群体模式」这一手法是否接受**的地方——但与海地革命的两个合成桥接人物完全同构，且此处更无可避免（史前史本就无名字）。

4. **[#27] 「哥贝克力石阵颠倒因果」作为假说而非定论**（§2 L4 / §4-3 / §5A / §7 / §10-5）
   - **问题**：「信仰/聚集**推动**了农业」是 Klaus Schmidt 等提出的、被广泛讨论但**未成定论**的假说。它很有冲击力，容易被读成「已证实的事实」。
   - **narrative 现状**：全程用「**很可能是反过来**」「**也许**」「**可能**」「一个**反直觉的可能**」呈现，且 §7 明确要学生「用同一批证据论证两个方向相反的因果链」——**已作为假说/思维训练呈现，未当定论**。§10-5 清坑也只说「**很可能**是信仰推动农业」。
   - **建议**：保持现状。**列此条仅为透明**——提醒下游 storyboard 若用此点，必须沿用「假说/可能」措辞，**禁止**排成「科学已证明宗教先于农业」。
