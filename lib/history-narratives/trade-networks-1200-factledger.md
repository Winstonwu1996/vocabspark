1. **[#20] 黑死病死亡率「约三分之一」的概数**（§4-10 / §6 / 附录 A）
   - **问题**：黑死病欧洲死亡率史学估计差异极大（常见 30%-60% 区间，部分地区更高）。narrative 统一用「可能三分之一」是偏**保守下沿**的标准教学口径。
   - **narrative 现状**：全程用「可能 / 约三分之一」，未写死值。
   - **建议**：现状**合规**（用「可能」留余地，且取保守值）。若要更严，可写「约三分之一甚至更多（估计差异大）」。低优先级。

2. **[#17] dhow「椰壳绳缝制、不用铁钉」+「靠看星星和闻风向认路」的感官细节**（§3 DEFAULT 视角 / 附录 B）
   - **问题**：「椰壳纤维缝制船板、不用铁钉」是 dhow 的**真实经典特征**（多源可核），不是编造。但「水手靠看星星和闻风向认路」「手掌被椰壳绳磨出茧」属于为 DEFAULT 视角设计的**合成感官细节**——技术/工艺基础真实，但具体到「这一个无名水手」的身体感受是叙事化的。
   - **narrative 现状**：作为 receiving-end 视角的感官 motif 嵌入，已在 §3 整体标注该人物为「虚构桥接人物，身份完全写实」。dhow 缝制工艺本身有据，未排成史料档案样式。
   - **建议**：① 接受现状（工艺真实 + 人物已标注合成）；② 这是本 topic 唯一一处「合成感官 motif」，与海地课 lambi 红旗同类——**建议创始人确认合成感官细节的处理是否接受**。无需改 narrative。

3. **[#8] 曼萨·穆萨压低开罗金价「好几年」**（§3 / §4-6）
