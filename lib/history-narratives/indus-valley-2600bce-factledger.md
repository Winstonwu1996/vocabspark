## 🚩 红旗句(创始人必审)

> 按影响排序。无事实硬伤;全部为已透明标注的推论/政治敏感解释/合成人物/措辞收紧,**无 needs-source 缺口**。本 topic 的红旗集中在「推论冒充事实」与「政治敏感解释」两类——narrative 均已显式分层处理,以下逐条复核。

1. **[#18/#17]「最平等社会」与「无王权中心」的措辞**(§2 L2 / §4-7 / §9 / §10-1 / §7)
   - **问题**:这是本 topic 最容易被读成「定论」的地方。学界确有「最平等早期复杂社会」的提法,但它**本质是推论**(基于「没挖到精英/王宫」),而「证据缺失」不能等于「不存在」。
   - **narrative 现状**:**处理优秀** —— frontmatter 史学警示、§2 L2「『看不见明显的国王和巨富』不等于『真的人人平等』」、§9「最平等派 vs 隐形精英派」、§10-1「『找不到精英』不等于『没有精英』...只是一个有力的可能,不是定论」、§7 专门把「absence of evidence」做成思维训练。双面**始终挂着**。
   - **建议**:现状**合规且示范级**。下游 storyboard 若引用「最平等」,**必须**沿用「这是有力推论、非定论」的并置,**禁止**单极化为「确定的乌托邦」。

2. **[#19]「祭司王」名字陷阱**(§5D / §4-7)
   - **问题**:「Priest-King」是 1920s 发掘者按想象起的名,**无任何证据**证明是祭司或王。若沿用而不拆解,会强化「古文明必有王」的误导。
   - **narrative 现状**:§5D **已显式拆解** —— 「这个名字是 1920 年代的发掘者按自己对『古代统治者』的想象起的...没有任何证据...关于这个文明有没有王,这尊雕像什么也证明不了」,并明确称之为「教学陷阱」。§10-2 再次清坑。
   - **建议**:保持现状。**列此条仅为提醒下游**:任何模块引用「Priest-King」**必须**带上「名字是后人想象、非确证」的标注,**禁止**当作「印度河有祭司国王」的证据排版。

3. **[#23/#24] Saraswati / 雅利安的政治敏感解释**(§2 L0 / §4-9 / §6 / §9 / §10-3)
   - **问题**:本 topic 最政治敏感处。① Ghaggar-Hakra=Saraswati 的认定、② 雅利安「入侵 vs 迁入」、③ 这个文明「是谁的祖先」(印 vs 巴),都直接牵动当代印度/巴基斯坦民族政治。处理不慎易被读成站队。
   - **narrative 现状**:**处理稳健** —— §9 **专设一段**标注「高度政治化」「把考古证据往民族叙事上拉」「在印度和巴基斯坦都直接牵动当代身份政治」「一个四千年前的文明,今天还在被争『它是谁的祖先』」;§10-7 清坑「核心遗址大量在今巴基斯坦...『它属于谁』本身就是当代争论」;§4-9 标注「在印度尤其政治敏感」。**主流学术结论(否定暴力入侵毁灭)与政治争议并陈,未站队。**
   - **建议**:现状**合规**。这是 Rule 0 最吃重的一段,**建议创始人重点过一眼 §9**,确认中立口径满意。下游 storyboard 触及 Saraswati/雅利安时,**必须**保留「学术结论 + 政治化争议」双层,**禁止**简化为任一民族叙事。

4. **[合成桥接人物] 三个文明内部主角全为合成**(§3 三视角 / 附录 C)
   - **问题**:本 topic 与海地不同——海地有真实主角(Toussaint 等),本 topic **文明内部一个有名有姓的古人都没有**,所以三视角(组织者 / Meluhha 商人 / 普通孩子)**全部**是合成桥接人物。合成密度高于一般 topic。
   - **narrative 现状**:§3 **逐个透明标注**为「虚构桥接人物,身份写实」,且**把「合成」本身变成教学点** —— 「故意不给王的头衔,因为我们至今没找到证据证明有国王」「没给名字,因为这个文明没有为任何普通人留下名字,甚至没有为它的统治者留下名字」。附录 C 明确分「外部真实人物 / 现代发掘者 / 合成角色」三类。**合成与真实清清楚楚分开,未冒充史料。**
   - **建议**:现状**合规**。三个角色身份(城市组织者 / Meluhha 贸易中介 / 网格城市居民)均有考古/文献支撑的**阶层真实性**,无姓名/具体事迹杜撰冒充档案。Sargon/Sahni/Banerji/Marshall 为真实外部人物,生卒已核。**无未标注的合成冒充史料。**

5. **[#6/#8] 推测性措辞:「罗马级排水」引语 + Great Bath 用途**(§1 / §4-3 / §5C)
   - **问题**:① 「先进到要等罗马人才有可比的排水」是**学者评价/引语**,非中性事实;② Great Bath「用于仪式性沐浴」是**推测**。两者若排成硬事实会越过证据。
   - **narrative 现状**:① §1 用「**有学者说**要等两千多年后的罗马人才造得出可以相比的东西」—— 已标为引语(Nat Geo 引学者原话);② §5C「很多学者认为...用于**仪式性沐浴**...但这是**推测**,不能当确证...我们**不确定**」—— 已显式标推测。
   - **建议**:现状可接受(均已软化为引语/推测)。低优先级。若想更保守,§1 可加「(学者评价)」四字,但非必改。
