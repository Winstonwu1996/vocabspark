## 🚩 红旗句（创始人必审）

> 只有 `needs-source` / `downgrade-wording` / `flagged` 三类进这里。每条给：问题 + 建议处理。

1. **[#23]** narrative §5 史料2「Williams 还**首次使用**了 "crimes against humanity"」+ §附B「Williams 1890 **首用**」+ §6「Williams 的 "crimes against humanity" 概念进入国际话语」
   - 问题：**绝对表述过强（重点 C 引语 + absolute）**。权威主流表述是「**one of the earliest usages / popularized**（最早现代用法之一/使之广为流传）」，不是严格「首次/首用」——该短语此前有零散出现，作为成型的国际法概念是 20 世纪（纽伦堡）的事。「首用」会被史实党挑刺。
   - 建议：把「首次使用/首用」改为「**最早系统使用之一 / 让这个说法广为人知**」。功劳真实（他确是关键普及者），只需去掉「第一」的伪精确。

2. **[#14]** `leo-n6`/`vil-n5` anti-fab 括号「1904……一个父亲盯着地上他**女儿被砍下来的小手**」（故事节点）vs narrative §5 史料3「**手和脚**」「Boali 被杀害」
   - 问题：**代表性/史实细节冲突（重点 5 代表性 + 引语锚）**。这张锚定照片（Nsala/Boali）的 documented 事实是：Boali（5 岁）**被 Abir 守卫杀害并食用**，Nsala 留下她的**手和脚**作证据。但两个故事节点（leo-n6/vil-n5）只说「被砍下的小手」，且嵌在「砍手=完不成配额的惩罚」+「很多被砍手者**还活着**，包括孩子」的语境里。读者可能把这张「被杀害儿童」的照片误读成「幸存的被砍手儿童」的代表。
   - 建议：narrative §5 已处理正确（手+脚、有名字、被杀害），**保留**。但故事节点 leo-n6/vil-n5 的括号短句宜：①补「手和脚」或不强调是「惩罚活人」的例子；②或把这张照片明确为「被杀害的孩子」而非「砍手幸存」的代表，避免把两类（活人被砍手 / 被杀害儿童遗体）混成一类。低-中优先级（narrative 主文已对，故事层措辞需对齐）。

3. **[#17]** `leo-n9`/`leo-n10`/`vil-n10`「无论哪个数，都是**种族灭绝级别**的」/「**种族灭绝级**抢劫」
   - 问题：**强分类表述 + 学界争议（重点 A 邻类）**。「genocide」标签在学界有真实分歧：intent-focused 派指 Leopold 目的是橡胶利润而非灭族，主张用「crimes against humanity/atrocity」。Hochschild 本人都说「genocidal proportions 但严格说不是 genocide」。
   - 建议：故事节点已多用「种族灭绝**级别/级**」（带 hedge），且 narrative §9 明示两派之争——**整体处理稳妥，可保留**。若要更稳，可在某处加「学者对是否算严格意义的 genocide 仍有分歧」一句。低优先级（已 hedge）。

4. **[#22]** `gw-n6`/`gw-n8`/`gw-n10`「历史上**第一份系统、公开、点名**向全世界揭发刚果暴行的文件」
   - 问题：**绝对表述（重点 C 邻类）**。Williams 公开信是揭发刚果的里程碑/催化剂，「第一份系统揭发」有支撑但偏绝对（早有零星批评，且「系统」的判定主观）。
   - 建议：可保留（学界确常称其为最早系统揭发），但更稳写法是「**最早系统、公开揭发刚果暴行的文件之一 / 首批**」。低优先级。

5. **[#5]** narrative §5 史料1 Leopold 1876 开幕词英译
   - 问题：**引语轻微措辞差异（重点 C）**。原文 "the only part of our globe **which it has yet to penetrate**" / "the darkness which **envelops** entire peoples"；narrative 英译作 "has **not** yet penetrated" / "hangs over"。属同义改写，实质准确。
   - 建议：narrative 中文简化版无碍；英译可微调对齐原文（"which it has yet to penetrate"）以求逐字精确。极低优先级。

6. **[#13]** `leo-n6`/`vil-n5`「被砍手的很多**还活着**，包括孩子」
   - 问题：**数字/概括与锚定证据张力（重点 A 轻类）**。作为一般陈述成立（确有从活人砍手的记录）；但紧贴的锚定照片（#14 Nsala/Boali）恰是**被杀害**的孩子，两句并列易生「砍手=对活人惩罚」的单一印象。
   - 建议：与 #14 合并处理——明确区分两类（活人被砍手 vs 砍下死者的手交差，两者制度上都存在）。低优先级。

7. **[#16]** `leo-n9`/`vil-n8`「学者们的估算，从几百万到一千万不等」（强修辞数字主审项，结论：**通过**）
   - 问题：**重点 A 刚果死亡数（著名争议数字）**。这是本 Topic 最该审的数字。Hochschild「~1000 万」被 Vansina 及近年人口史研究批评高估（橡胶省外推全刚果）；精确数不可知（账本被烧）。
   - 结论：故事与 narrative §9 均用「**几百万到上千万**的保守区间」并明示「没有精确数字/账本被烧/historiography 之争」——**这是教科书级正确的 hedge 处理，无需改动**。列此条仅为留痕：审查已覆盖此著名争议数字，结论是 verified（已恰当不确定性标注）。✅ 非应改项。
