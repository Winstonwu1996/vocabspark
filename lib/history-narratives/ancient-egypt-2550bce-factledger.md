## 🚩 红旗句（创始人必审）

> 全部为 ⚠️downgrade-wording（称谓/措辞收紧），**无事实硬伤、无缺来源、无演绎未标注**。按影响排序。

1. **[#12]** `「一个叫 Merer（梅雷尔）的工头记的」`（storyboard `khufu-n5` CN"工头" / EN"a foreman named Merer"）
   - **问题**：Merer 的真实称号是 **inspector（埃及语 sḥḏ / sehedj，中级监工/检查官）**，他统领约 40 名船工组成的一个工班（phyle）。narrative kernel §5A 与 notebook 都已正确写作"中级监工 / inspector / 中级官员"——只有 `khufu-n5` 这一处口语化成了"工头 / foreman"。"工头"会让人以为他是工地上督工搬石头的班头，而他实际是负责船运补给/记账的中级行政监工。这是 3 个文件里**唯一一处**与已正确写法不一致的称谓。
   - **建议**：把 `khufu-n5` 的"工头"改为"监工"（EN: "a foreman named Merer" → "an inspector named Merer" 或 "a mid-level official named Merer"），与 kernel/notebook 对齐。低-中优先级，但因是一手史料人物的身份且文件内部不一致，建议改。

2. **[#19]** `「后世找遍埃及，唯一能确认是我本人的雕像，是一尊只有 7.5 厘米高的小象牙像」`（`khufu-n8`；kernel §3"今天唯一确认是 Khufu 的雕像"；notebook"唯一确认是 Khufu 本人的雕像"）
   - **问题**：精确说法是"**唯一基本完整保存**的三维 Khufu 像"（维基："the only three-dimensional depiction of Khufu that has survived …… nearly completely"）。实际上还出土过其他 Khufu 雕像的**碎片**（fragments）。"唯一确认是他本人的雕像"语气偏绝对，可能让学生以为除这尊外**毫无**任何 Khufu 造像。注：khufu desc 与 kernel §3 旁处已有"几乎不知道他长什么样"的软化表述，张力本身不依赖绝对化。
   - **建议**：加"基本完整 / 完整保存"限定——"唯一**基本完整保存**的 Khufu 雕像"（EN: "the only statue confirmed as me" → "the only largely-intact statue of me"）。这反而**强化**"最大的山配最小的脸"反讽（一尊完整小像 vs 一座大山），不削弱叙事。低优先级，属绝对表述按 SOP 收紧。

3. **[#13/#15]** `「国家每天宰牛」/「天天有肉吃」`（khufu-n7，hem-n5，lab-n3，kernel §3/§5B）
   - **问题**：**不是事实硬伤**——工人城出土大量牛骨/鱼骨，肉类供给充足是考古实证，"破奴隶神话"方向完全正确。唯一可收紧的：考古证据支持的是"工人有相当丰富的肉食供给（牛/鱼）"，"**每天**宰牛 / **天天**有肉"是把"供给充足"推到"逐日恒定"的程度，原始证据是骨量堆积的总体推断，非逐日配给账。文中已用"国家把他们当资产维护"的冷静框架平衡，未滑向"快乐工人"。
   - **建议**：可保留（7 年级冲击力 + 与"村里一年吃不上几次肉"对照有效）；若要更严，把"每天宰牛 / 天天有肉"软化为"经常宰牛 / 常有肉吃 / 肉食供给充足"。**列此条主要为透明**，非必改。

4. **[#27]** `「法老的儿子哈夫拉（Khafre）…… 接着在吉萨建塔」`（hem-n9，kernel §6/附录 A，notebook）
   - **问题**：**不是硬伤**——Khafre 确为 Khufu 之子，确建第二金字塔 + 狮身人面像，文中用"接着"未声称直接继位，严格成立。唯一透明提示：Khufu 的**直接继承者其实是 Djedefre**（在 Khufu 与 Khafre 之间短暂在位并建 Abu Rawash 金字塔），Khafre 是稍后即位的另一个儿子。现行表述不会致误，但若学生追问"Khufu 下一任是谁"，标准答案是 Djedefre 而非 Khafre。
   - **建议**：可保留现状（无错）；若想更完备，可在 notebook/kernel 附录加一句脚注"Khufu 之后先有 Djedefre 短暂在位，再到 Khafre"。**最低优先级，纯透明，非必改。**
