## 4. 48 小时后回忆（隔两天，不看页面，口头问）— Gate 3 硬指标

**通过线：≥ 2 个具体事实 + ≥ 1 个因果，仍记得。**

**constitutional-convention-1787 — 该留住的：**
1. 1787 年在费城写了美国宪法。
2. 宪法把被奴役的人算成「3/5 个人」。
3. Mum Bett（一个被奴役的女性）1781 年打官司赢回了自由，用的是"人人生而自由"。
4. 宪法正文里**不敢写**"奴隶"这个词。
5. （因果）因为要平衡大州/小州 + 南方要席位 → 3/5 妥协 → 几十年后烧成内战。

**chinese-exclusion-1882 — 该留住的：**
1. 华工修了横贯大陆铁路最难的 Sierra Nevada 段。
2. 1882 排华法案 = 美国第一部按种族禁止整个民族移民的法。
3. 已在美国的华人**永远不能入籍**、不能接家人团聚。
4. 这部法管了 **61 年**（1882→1943）。
5. （因果）因为铁路修完 + 排外政治 → 当初用命修路的人被一部法律关在"美国人"之外。

> 问的时候别提示答案。她答出 ≥2 事实 + ≥1 因果 = 这个 topic Gate 3 过。

## 5. dark topic 边界（chinese-exclusion 专判）

任一出现 = dark 未过、要改：
- ❌ 创伤模拟感（"像我在被害/被杀"）
- ❌ 被操纵感（"它在硬逼我难过/感动"）
- ❌ 退缩（"太惨了不想学/想跳过"）
- ✅ 期望：见证者式"我知道了、记住了、想多问"
