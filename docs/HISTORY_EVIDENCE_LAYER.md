# History 证据层（Evidence Layer）— 设计 doc

**Status**: 方向锁定 v1 — founder 2026-05-23 拍板
**触发**: founder 读完 `docs/CODEX_AUDIT_history_sop.md` + 抽样文稿后的结论
**关系**: 不替代 `AUTHORING_PIPELINE.md`（生成 SOP）/ `STORY_FIRST_PEDAGOGY.md`（教学法）；
在它们之上加一层**独立证据校验**。本文档锁定后，二者按本文吸收。

---

## 0. 核心判断（为什么要有这一层）

**最大单点结构风险：缺少独立证据回路。**

现在系统能证明的：内容能生成、节点结构一致、AI reviewer 能发现不少问题、前端能跑通。
**还不能证明的三件事**：

1. **学生真学会了**，而不是看完一段很强的故事。
2. **历史事实足够稳**——尤其数字、因果、引语、代表性人物。
3. **中立性真成立**，而不是被叙事视角和默认 lens 偷偷决定了。

> 这不是否定方向。story-first 对 Willow 这类学生是对的。但要把它从"好故事产品"
> 推进成"**可信学习产品**"，必须加外部校验层。**风险不是"工程质量不够"，
> 而是"工程自洽掩盖了教育有效性 + 史实置信度不足"。**

**下一步不继续只加强 prompt，而是加两个硬机制**：
- **Fact Ledger**（事实账本）— 解决风险 #2/#3 的史实/代表性底座
- **Learning Receipt**（学习证据）— 解决风险 #1 的学习有效性

---

## 1. 教学逻辑修订：story-first, **not** story-only

"先叙事、末尾再思辨"**不做成绝对规则**。7 年级刚来美国的孩子确实要先建 schema
（一上来 Socratic 只会空转），但全程主要是阅读、到最后才写 → 风险是进入"被动听故事"模式。
N6/N10/N12 已比早期强，但还需要**轻量主动认知**。

### 1.1 micro-check（每 2-3 个读节点插一个）
- 形式**轻**：选择 / 预测 / 复述一句 / 语音回答一句。不一定写长文。
- 目的**不是考倒她**，是防"读完很感动、但什么都没抓住"。
- 与现有 expectsRealAnswer 重写门的区别：micro-check 是低摩擦的，不算"2 个输入节点"的硬写作门。

### 1.2 三视角自洽 + 明确"你只听了一边"
三视角有价值，但**用户只跑一个 lens 就离开 → 三视角收益失效**。所以：
- **每个 lens 必须自洽**（单独跑也成立）。
- 第一个 lens 结束给一张 **"missing perspective" 小卡片**（你现在只听到了一边）。
- **mastery 问题明确要求学生承认视角限制**。
- 第二、第三 lens **带真正的冲突信息**，不只是换个人物重讲。

### 1.3 dark topic 红线（受害者 / 集中营 / 屠杀 / 奴役 / 排华 / 拘禁营）
用"**见证者声音**"，**不做"创伤模拟"**。固定红线：
- ❌ 不用"你正在被折磨 / 被杀"的沉浸式指令。
- ✅ composite 角色**必须**标明是综合人物。
- ❌ 不用感官渲染换情绪强度。
- ❌ 不把痛苦做成游戏奖励。

> 注：历史老师 2026-05-23 审 22 草稿确认当前已基本守住（receiving-end 是"见证"不是"模拟"），
> 本条把它从"实践"升格为"硬红线"，防回归。

### 1.4 DeepSeek runtime 即兴回答分三类（不只靠 prompt）
用户随时 branch 提问时，回答按类处理：
| 类别 | 处理 |
|---|---|
| **课件内已知** | 正常答 |
| **相关但课件外** | 明确说"这个超出本节材料，我可以先给一个谨慎解释" |
| **争议 / 不确定** | 标明有争议，给多方，不下结论 |

## 2. 生成 SOP 增补

### 2.1 失败类型 taxonomy（不是继续堆规则，是加一层分类）
12 铁律有"上一场事故驱动"的问题。补一层**失败类型**，让作者 + reviewer 按类自检：
| 失败类型 | 说明 | 例 |
|---|---|---|
| **数字夸张** | 强修辞数字必须进事实账本 | "每一米铁路就死一个华工" |
| **因果过度** | 单一解释压平复杂事件 | 某战争"就是因为 X" |
| **引语风险** | 真实史料 / 演绎句 / 概括句必须严格分层 | 把演绎句排成档案样式 |
| **代表性风险** | 一个人物偷换成整个群体 | 一个角色 = "所有华工" |
| **composite 风险** | 合成人物必须透明 | 未标注的虚构姓名/年龄 |
| **情绪强度风险** | 越有感染力的句子，越要查事实底座 | 催泪句压过事实 |

### 2.2 节点预算 justification（N6/N10/N12 是好默认，**不是铁律**）
历史材料有自己的形状：有些适合 9 节点，有些适合 13。SOP **要求作者说明**：
"为什么这个 topic 适合这个节点预算"。固定 qaTemplate 档位作为起点，但允许带理由偏离。

### 2.3 "明朝那些事儿密度" 的 proxy 指标（机械近似）
密度不能机械验证，但可用 proxy：
- 每 100 字**具体名词**数量
- **日期 / 地点 / 人物 / 制度锚点**数量
- **抽象词比例**
- **段落长度**
- ⭐ **学生 5 分钟后能否复述 3 个具体事实**（最重要——接到 Learning Receipt + pedagogy smoke gate）

## 3. 硬机制 1：Fact Ledger（事实账本）

**目标**：创始人**不逐字审 22 个 topic**，只审**事实账本 + 红旗句**。

每个 topic 自动抽取 **20-30 条高风险 claim**：
- 日期 / 数字 / 引语 / 因果判断 / 人物动机 / 群体代表性 / 绝对表述（"第一次/最大/从未"）/ 情绪很强的修辞句

每条标注**来源等级**：
| 等级 | 含义 |
|---|---|
| `primary` | 一手史料 |
| `textbook` | textbook / AP CED |
| `encyclopedia` | 权威百科 |
| `inference` | 推断 |
| `dramatization` | 演绎（必须降级措辞或显式标注）|

**产物**：`lib/history-narratives/<topicId>-factledger.md`（或 .json）。
**Gate 规则**：所有高风险 claim 必须有来源，或降级为谨慎措辞，否则不进上线 gate。

---

## 4. 硬机制 2：Learning Receipt（学习证据）

**目标**：每节课结束，学生**必须留下学习证据**，系统才能逐步证明"孩子真学到了"。

四件证据（lens 完成时收集）：
1. **一个事实锚点**（一个具体的事实）
2. **一个因果解释**（为什么会这样）
3. **一个视角限制**（我刚才只听到了谁的一边）
4. **一个英文表达**（接 VocabSpark 主业 — 英文学习闭环）

> ⚠️ 这是 runtime + 存储 schema 改动，触及 live 用户进度。设计必须遵守
> "**千万不要影响用户进度**" 铁律：新增字段纯附加，不动 turnIndex 语义，老用户零风险。
> 实施前单独走 Codex 审 + 备份分支。

## 5. 审核 SOP：Rule 0 中立性三 reviewer

中立性**不是"语气看起来平衡"**，而是要问：
- 谁获得**内心复杂性**？谁只是被当成受害者或反派？
- **默认 lens 是否已经替学生决定了结论？**
- 中国学生会不会被引向**单一类比**？
- 美国主流教材视角和 receiving-end 视角**是否都被公平呈现**？

**用三个 reviewer，比较三者认为"学生会得出什么结论"**：
1. **AP / 美国主流教材视角**
2. **receiving-end / postcolonial 视角**
3. **中国学生桥接视角**

三者结论分歧大 → 默认 lens 或叙事 framing 有隐性立场，需调。

---

## 6. Dark → 上线：四级 Gate

不一次性全审完 22 个再上线，也不直接全放。**四级门 + 分难度**：

| Gate | 内容 |
|---|---|
| **1. Mechanical** | import/build、节点数、必写节点、quote badge、object hook、无双尾部写作 |
| **2. Fact Ledger** | 高风险 claim 全部有来源或降级措辞（机制 3）|
| **3. Pedagogy smoke** | 默认 lens 让真实/模拟 7 年级用户跑，测**即时回忆 + 48 小时回忆** |
| **4. Limited beta** | 只进 hidden/admin registry，收集跳出率、N6/N12 答案质量、查词、追问、卡点 |

**分难度放行**：
- **优先上线**：低争议、结构清楚的主题。
- **更强 gate**：Chinese Exclusion / Manzanar / Holocaust / Cold War / Congo / Trail of Tears。

---

## 7. 一句话总结

> 保留 story-first + 三 lens（这是产品差异化）。下一步不再只加强 prompt，
> 而是加两个硬机制 —— **Fact Ledger**（证明史实稳）+ **Learning Receipt**（证明学生学到）——
> 让系统从"工程上跑通的好故事"变成"能逐步证明孩子真学到了历史"。
