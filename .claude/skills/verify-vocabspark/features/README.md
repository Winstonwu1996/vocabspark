# 功能地图

每个文件一个用户能碰到的功能，写从用户角度怎么走到、怎么驱动、看到什么才算证明。先覆盖的是最近用户真撞到过的四个问题，每条都有对应的修复提交和单测；这里补的是「像用户一样走一遍」。

| 文件 | 功能 | 来历 | 能不能跑 | 跑过 |
|---|---|---|---|---|
| [network-banner.md](network-banner.md) | 顶部「网络已断开」提示 | Willow 登录时误报、报了不消失（b924f38） | 游客，零花费 | 2026-11-20 跑通 |
| [review-progress.md](review-progress.md) | 快速复习的进度和「加练」 | 梧桐：标了不熟，总数越做越多（4e474a9） | 游客，学词要调 AI | 没跑过 |
| [cloze-options.md](cloze-options.md) | 阅读理解选项顺序 | Willow：答案总在第一个（58afa8d） | 要登录：游客一天只能学 5 个，阅读理解每满 10 个才出 | 跑不了 |
| [daily-target-after-login.md](daily-target-after-login.md) | 登录后每日新词数 | 梧桐：设了 30，登录后变成 10（28d8f4f、6ccb74a） | 要登录 | 跑不了 |

「跑不了」的两条缺的是一个测试账号：线上没有，登录要收验证码邮件。要不要建、用哪个邮箱，William 定。

每个文件的四节固定：`子功能`、`怎么走到（用户视角）`、`用内置浏览器驱动`、`坑`。跑完把「跑过」一栏改成日期和结果。
