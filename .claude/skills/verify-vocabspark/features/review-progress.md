# 快速复习的进度和「加练」

页面 `pages/vocab.js` 的快速复习（`startQuickReview`），进度口径在 `lib/reviewProgress.js` 的 `computeReviewProgress`。标「模糊」或「不认识」的词会当场排到队尾再练一遍；进度的分母锁成本轮去重后的词数，再练一遍不加分母，页面上标「🔁 加练」。

## 子功能

1. **分母不涨**：整轮下来，「快速复习 X/Y」里的 Y 一直不变，标几次不熟都一样。
2. **加练有标记**：再练的那个词，题头显示「🔁 加练 · 刚才标了不熟，趁热再练一遍（不增加今天的复习量）」，进度后面带「· 加练」，X 不往前走。
3. **做得完**：走到队尾，X 等于 Y，进入复习完成页。

## 怎么走到（用户视角）

游客打开 `/vocab`，先学几个新词（游客一天最多 5 个）。学完以后点右上角「⚙️」（`aria-label="打开设置"`），设置里点「🔄 快速复习」，复习全部学过的词。这一入口是「✍️ 默写复习」：每题先在空框里写中文意思，点「对答案 👆」（想不起来点「想不起，直接看答案 →」），再在「🟢 彻底掌握」「🟡 仍不确定」「🔴 面临易错」里选一个。

（另一种「⚡ 快速重测（清积压）」是翻卡加「🟢 认识 / 🟡 模糊 / 🔴 不认识」，只在有积压时从首页进，不是这条流程。）

## 用内置浏览器驱动

还没真跑过。第一次跑时把下面的步骤补成实际走通的样子，按钮的字以页面为准。

1. `new-run.sh review-progress`，清场成干净游客。
2. 学新词：照页面引导走到学完至少 3 个词（这一步调 DeepSeek，几分钱）。学词的入口和步骤第一次跑时补进这里。
3. 打开设置 →「🔄 快速复习」。题头标签应为「✍️ 默写复习」。记下进度文字「快速复习 1/N」里的 N（`get_page_text` 找「快速复习」；进度把当前这个词算进去，第一题就是 1/N）。
4. 第一个词评「🟡 仍不确定」，第二个评「🔴 面临易错」，其余评「🟢 彻底掌握」。每答一题记一次进度文字和有没有「🔁 加练」。
5. 判据：每一笔的 N 都相同；轮到前面评过不熟的词时出现「🔁 加练」且进度后面带「· 加练」、X 不前进；最后进入完成页前 X 等于 N。

## 坑

- 游客一天只能学 5 个新词。清场（清 localStorage）会把当天计数也清掉，所以每次跑都能重新学；但这是游客的本机计数，不是线上数据。
- 学新词要等 AI 生成讲解，慢的时候十几秒。
- 「面临易错」（forgot）最多当场再练 2 次，「仍不确定」（fuzzy）1 次，所以题数最多是词数的 3 倍，一定会结束。
