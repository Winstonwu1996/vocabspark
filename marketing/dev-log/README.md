# Marketing Dev-Log — Know U. Learning 开发日志

## 这是什么

Know U. Learning 创始人 Winston 在产品开发过程中**实时**沉淀的思考、决策、
顿悟、失败、恢复——给后续营销 Agent 作素材。

## 营销定位（钉死）

**主轴叙事**：一个**中国移民父亲**——不会写代码，孩子在加州 7 年级——
用 AI 给 12 岁女儿做了一款解决**自己当下能体感到痛点**的产品。

**核心读者**：和我一样的**中国移民家长**——孩子在美国学校，自己辅导不了
社会课/英文/历史，外面的私教很贵但也只能复习课本，市面上的 AI 工具又
不放心。我们都焦虑过同一件事——**孩子在两个体系中间，到底学到了什么**。

**Voice（每篇 entry 必须遵守）**：
- **以父亲第一人称写作**——"我半夜想..." / "晚饭桌上她说..." /
  "我老婆问..."。不是"创始人"。不是"产品负责人"。**是爸爸**。
- **唤起其他华人家长的共鸣**——具体到他们认得的场景：开家长会、Costco
  路上、辅导作业到 10 点、AP 备考焦虑、孩子忘了中文、孩子说"妈妈在中国
  我们家不那么穷"那种心刺。
- **技术语言压到最低**——"fact-check"说"检查事实"；"hallucination"说
  "AI 编了根本不存在的东西"；"two-tier architecture"说"两层分工"；
  "ROI"说"值不值"。**实在绕不开的术语**用一句话给非工程读者解释。
- **深度共鸣 > 工程精确**——同一件事可以工程化讲（"我们设计了对照实验"）
  也可以父亲化讲（"我那天晚上没睡，把新旧两版打开同时跑了 6 段对话"）。
  **始终选父亲化的那个版本**。
- **痛点要具体到能扎心**——"她背下来了但没真懂"是金句。"教育要培养思辨
  能力"是空话。**金句永远胜空话**。
- **解药要清晰但克制**——我们不卖灵丹妙药。我们卖的是**一个跟你一样焦虑的
  父亲想清楚的方式**。家长信任来自"我也想过这个，我也试过那个，我现在
  想清楚了一点"——不来自"我们是教育专家"。

**避免**：
- 自吹"我用 AI 几小时做了大产品"——我们的杠杆是**慢工细作**：每个决定
  都来自一个具体的家庭场景
- 装"工程师" / "硅谷创始人" — 我们是中国移民父亲。这是优势不是劣势
- "颠覆教育" / "AI 革命" 大词 — 我们配合学校教育，不替代
- "硬核技术" 内容流量陷阱 — 工程细节给工程师的读物，**家长读物里只
  保留与他们生活相关的那一层**

## 文件结构

```
marketing/dev-log/
├── README.md          ← 你正在读
├── INDEX.md           ← 时间倒序索引（一句话每条）
├── template.md        ← 写新 entry 的模板
└── entries/
    └── YYYY-MM-DD-{slug}.md
```

每个 entry 有结构化 frontmatter（date / theme / story-arc / key-numbers /
willow-related / pull-quotes / marketing-hooks），方便营销 Agent 按主题/数字
检索。

## 写作约束

1. **场景具体到可视化** — "晚饭桌上她脱口而出 1215，我多问一句她说不出来"
   比 "孩子背了不懂" 强 10 倍。读者要能看见画面。
2. **承认失败** — 失败是最好的故事钩子。一遍过的成功没人想听。
3. **数字要真** — 钱、字数、时间、成本——能量化的尽量量化（建立信任）
4. **Willow 出场要克制 + 真实** — 她是 12 岁孩子有隐私。出场用"女儿"或
   "Willow"都可以，但**保留她真实的反应**（"它说话好乱，我答不过来"）。
   过滤掉具体校名以外的隐私（朋友名字 / 老师名字 / 家庭住址等）。
5. **AI 协作要诚实** — "Claude 帮我想到这一步"是真话。**我们不假装独自
   完成**——这反而是我们故事最有力的地方："父亲 + AI 合作做产品"是大多数
   家长能想象的协作模式。
6. **中性 / 不踩"美国 vs 中国"** — 产品定位双向尊重，营销也必须。
7. **每篇 entry 至少有一个"扎心金句"** — 别的家长看到点头："对，我也想过这个"。
   写完后自己读一遍，问自己："如果我是另一个跟我一样焦虑的爸爸，这一篇
   会不会让我转给老婆？"如果不会，重写。
8. **结尾不能像创业者发言** — 结尾要像爸爸跟另一个爸爸聊完天的感觉。
   **不要喊"加油"或"做大事"**。要"你应该也懂的吧"那种克制。

## 营销 Agent 接入约定

营销 Agent 启动时：
1. 读 `INDEX.md` 拿到所有 entry 索引 + 一句话摘要
2. 根据当前 campaign 主题，按 frontmatter 里的 `theme` / `marketingHooks`
   筛选相关 entries
3. 全文读取相关 entries
4. 生成营销内容时**保留具体细节、数字、引语**——不要泛化成空话

## 频率

每个产品里程碑 / 每次重大决策 / 每个失败-恢复都写一篇。**最少每周 1 篇**。
不强求文字漂亮——具体、真实、有数据，就够营销 Agent 加工了。
